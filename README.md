## Initial Project Ideas 

(Mix of Exploratory + Applied)


### 1. **Campaign Performance Dashboard**
*Track key metrics (spend, reach, CTR, conversions) across channels using Python + simulated Redshift data + Quicksight visuals.*

- Focus: Data pipeline, aggregation, dashboard storytelling
- Skill Tags: SQL, data transformation, visualisation, KPIs

### 2. **Customer Segmentation for Targeted Email**
*Use demographic and behavioural data to segment customers into audiences for campaigns.*

- Focus: Feature engineering + unsupervised learning (clustering)
- Skill Tags: Pandas, k-Means, profile summaries, personas

### 3. **Churn Prediction with Historical Viewing Behaviour**
*Simulate a dataset of streaming views and build a churn model using logistic regression.*

- Focus: Predictive modelling + marketing insight
- Skill Tags: Python, supervised ML, storytelling with data

### 4. **Title Recommendation Engine for New Users**
*Use similarity scores to recommend titles to cold-start users (k-NN or content-based).*

- Focus: Recommender systems with simplified logic
- Skill Tags: k-NN, pandas, metadata features

### 5. **Automation Bot: Email Campaign Summary Generator**
*Use a Python script to automatically pull campaign results and format them into an email.*

- Focus: Workflow automation + reporting
- Skill Tags: Python, scheduled jobs, Markdown/email formatting
